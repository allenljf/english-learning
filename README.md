# 職場英文練習室 / FAB English

為初學者準備的電子製造與職場英文教材：閱讀、語句單字填空、文法三大學習區，全部採固定資料，無登入、無後端、無外部字型或套件依賴。

## 直接開始

- [開啟本機網頁](index.html)：用瀏覽器開啟，保留同資料夾的 `app.js`、`data.js`、`styles.css` 與 `docs/`。
- [完整 Markdown 全冊](docs/00-complete.md)：包含所有教學、詞庫、題目與解析。
- [學習指南與八週計畫](docs/01-guide.md)
- [1,139 字分類索引](docs/07-vocabulary-index.md)
- [YouTube 中文 TOEIC 影片資源（12 支）](docs/14-youtube-toeic-resources.md)
- [網站網址與使用流程規劃](docs/13-site-plan.md)

若瀏覽器不方便直接開 HTML，在此資料夾執行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

再開 [本機學習網址](http://127.0.0.1:8765)。僅供自己的電腦使用；終端機關閉後網址會停止，直接開啟 HTML 的方式不受影響。

## 教材內容

| 內容 | 數量與範圍 |
| --- | --- |
| 單字 | 1,139 個不重複拼字，23 類；附中文、詞性、常用搭配 |
| 時態 | 12 種教學常用組合 × 主被動 × 肯定否定疑問，共 72 格 |
| 動詞 | 全庫 269 個動詞五態，另列 64 個常用不規則動詞 |
| 詞族 | 34 組對照案例，包括同一詞根的不同修飾用法 |
| 文法 | 基本句型、人稱、冠詞、數量、情態、動名詞、不定詞、比較、子句、分詞、假設等 |
| 介系詞 | 時間、位置、方向、動詞及形容詞搭配，附易錯對比 |
| 練習 | 36 填空 + 36 文法 + 40 閱讀 + 8 段落填空 = 120 題 |
| 閱讀 | 10 篇題組，含雙／三文件；另有 2 篇段落填空。附中文、證據、逐項解析 |

同字不同詞性合併計數，不把 checks、checked 當成新的核心單字。常見搭配以片語呈現；完整句子另見文法、詞族、變化矩陣及練習。本教材列出可套用的主要組合，並非聲稱窮盡所有英文句子或每個字的字典義項。

## 網站操作

- 單字：搜尋英文、中文、搭配；篩情境、翻頁、遮中文；展開看動詞五態。
- 閱讀：先看方法，再選題組；先作答，再看中文及逐項解析。
- 填空：單句或段落模式，單句可篩詞性／介系詞等主題。
- 文法：教學、介系詞、詞族及練習四個分頁。
- 時態：切換時態、語態與肯定／否定／疑問；罕見被動有提示。
- 教材：可閱讀章節、下載全冊與分冊。

答題紀錄只留在當次頁面記憶體；切換分頁保留、重新整理清除。首次選擇後鎖定該題，使用「重做這組題目」可清除這組紀錄。計分只是自學記錄，不換算 TOEIC 成績。

## 編輯與重新產生

`content/` 保存教材原文與資料。`tools/build_questions.py`、`tools/build_reading.py` 保存原創題目；`tools/build_transformations.py` 保存時態矩陣。

```bash
python3 tools/build.py
python3 tools/validate.py
node --check app.js
node --check data.js
```

`build.py` 會重建題目 JSON、`data.js`、分冊與全冊。不要只修改生成的 `data.js` 或生成分冊；應修改對應原文或建置腳本。網站只需靜態檔，不需要 Python 才能開啟；Python 只用於可選的本機伺服器與內容重建。
