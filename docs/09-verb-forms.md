# 動詞五態與不規則表

以美式拼字為主；五欄依序為原形、三單現在、過去、過去分詞、現在分詞。be 的 am/is/are 須按人稱選，不全是三單。read 過去與分詞拼法相同但讀 /red/，現在原形讀 /riːd/。gotten 常見於美式；get 的具體完成式用法仍須依語意判斷。cost 表成本通常 cost–cost；作估價可見 costed。
