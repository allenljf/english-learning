# 本機學習網站規劃

## 學習者與目標

對象：想準備電子廠招募英文、類 TOEIC 閱讀與語句推理的新手。目標是從「背中文答案」轉為能辨識句子骨架、依情境選詞形、用證據解閱讀。

技術：純 HTML、CSS、JavaScript；固定內容載入 `data.js`，不呼叫 API，不必安裝前端框架。預設以 `index.html` 雙擊開啟；網址展示以 `http://127.0.0.1:8765` 為例。這是本機網址，不是公開網站。

## 三條學習案例

### 案例 A：閱讀看得慢

進閱讀區 → 看主旨／細節／推論差異 → 選 R01 公告 → 不看中文先選答案 → 解析找 visitors 與 employees 的不同 → 把自己的錯因記為 E（證據） → 次日重做 → 再做 R06 三文件。

成功標準：不只是答對，還能指明正確答案對應哪一句，以及誘答把哪個條件改掉了。

### 案例 B：單字認得卻不會填

在單字庫查 `inspect` → 對照 inspect／inspection／inspector → 在填空區做詞性題 → 發現 a final 後需名詞 → 到詞族章寫一組新句 → 次日遮中文回想。

成功標準：能把 `The inspector inspected it.` 改成 `An inspection is required.` 並說明主詞與詞性的改變。

### 案例 C：過去式與完成式混淆

讀文法時間決策 → 打開變化實驗室 → 切過去簡單與現在完成 → 比較 yesterday 與「對現在有關的結果」 → 改否定、疑問 → 到文法練習篩時態相關題。

成功標準：知道 `Did she check?` 不寫 checked；能分辨 `was being checked` 的過程與 `has been checked` 的完成結果。

## 畫面與資料規則

桌面左側導覽、右側學習內容；閱讀練習以原文與題目並排，窄螢幕改上下排列。大表格只在表格區水平捲動，不擠壓整頁。單字每頁 36 字，無結果提供清除按鈕。

所有選項可用鍵盤作答；首次作答後鎖定、立即顯示理由；答錯以文字說明，不只靠紅綠色。各題組可重做。資料僅保留當次頁面期間，沒有登入、雲端進度、跨裝置同步或分數預測。
